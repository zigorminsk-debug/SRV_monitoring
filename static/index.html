Подключить агент

Агент сам отправляет heartbeat на сервер через HTTPS. Открывать входящие порты на удалённой площадке не требуется.

!
Скопируйте токен сейчасСекрет больше не будет показан. При потере создайте новый агент.
Установка на WindowsСкопируйте файл в папку агента и запустите python monitor_agent.py --config agent.json. Пример службы Task Scheduler — в README.
